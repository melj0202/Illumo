Kikuta Variable Font
====================

Kikuta is a modular sans serif by Erwan Le Retif, created for "Emulare:
Imiter la machine pour mieux la preserver". It is distributed under the SIL
Open Font License 1.1 (see OFL.txt; source: https://fontesk.com/kikuta-font/).

Kikuta-Variable.ttf is a variable font with one axis:
  wght  1..1000 (named instances Thin 100 .. Black 900)

It covers A-Z, a-z, 0-9 and ! " & ' ( ) , - . / : ; ? @ [ \ ]. The engine
font service ("kikuta:<weight>") draws the other printable ASCII characters
from Space Mono.
